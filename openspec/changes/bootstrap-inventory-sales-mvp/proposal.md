# Proposal: Bootstrap Inventory Sales MVP

## Why

Nhóm cần một nền tảng dự án WinForms quản lý kho và bán hàng đủ rõ để mỗi thành viên có thể clone repo, đọc tài liệu và triển khai phần được giao ngay.

## What

- Tạo solution WinForms .NET 8 theo mô hình 3 lớp.
- Tạo database schema và seed data cho SQL Server LocalDB.
- Tạo service contract ban đầu giữa UI và backend.
- Tạo docs phân công, workflow, quy chuẩn chung và checklist demo.
- Tạo UI placeholder để Châu tiếp tục hoàn thiện giao diện.

## Scope

Bao gồm nền móng project, tài liệu, schema và contract. Chưa triển khai DAL ADO.NET thật cho toàn bộ CRUD trong change này.

## Success Criteria

- Solution build được.
- Có đủ project WinForms, BLL, DAL, DTO, Tests.
- Có docs để Dũ và Hùng đọc là bắt đầu làm được.
- Có OpenSpec change đầu tiên để làm nguồn kế hoạch.
