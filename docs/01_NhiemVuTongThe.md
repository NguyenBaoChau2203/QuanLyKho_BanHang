# Nhiệm vụ tổng thể

## Mục tiêu

Xây dựng phần mềm quản lý kho và bán hàng bằng WinForms, áp dụng mô hình 3 lớp, có đủ nghiệp vụ cơ bản để demo như một ứng dụng thực tế nhỏ.

## Phạm vi MVP

- Đăng nhập và phân quyền cơ bản.
- Quản lý sản phẩm, loại hàng, nhà cung cấp, khách hàng.
- Nhập kho và tự động tăng tồn.
- Bán hàng và tự động giảm tồn.
- Không cho bán vượt tồn kho.
- Kiểm kê kho và ghi nhận chênh lệch.
- Dashboard doanh thu, tồn thấp, top sản phẩm.
- Báo cáo doanh thu theo khoảng ngày.
- Trợ lý quản lý rule-based cho các câu lệnh phổ biến.

## Điểm nâng cấp tạo khác biệt

- Dashboard vận hành cho quản lý.
- Cảnh báo hàng tồn thấp.
- Chat box/trợ lý quản lý hybrid: rule-based trước, AI API sau nếu còn thời gian.
- Audit log để biết ai thao tác gì.
- Xuất/in hóa đơn nếu kịp.

## Tiêu chí hoàn thành

- Solution build được.
- Có database schema và seed data.
- Luồng nhập kho, bán hàng, tồn kho chạy đúng.
- UI có menu điều hướng đầy đủ.
- Dashboard có dữ liệu thật khi backend hoàn thiện.
- Có tài liệu nhóm, workflow GitHub và OpenSpec change.
